# 【每日大模型行业情报简报】

**日期：2026年05月24日**
**编制：AI 行业投资顾问**

---

### 一、 核心摘要

今日市场呈现明显的**“双雄争霸，巨头追赶”**格局。**DeepSeek** 凭借 `V4-flash` 模型以断层优势占据用量榜首，显示出极强的市场渗透力；**Tencent** 的 `hy3-preview` 异军突起，用量紧随其后，成为本周最大黑马。**Anthropic** 在高端模型领域持续发力，`Claude-4.x` 系列包揽 LMArena 跑分前四，技术护城河加深。相比之下，**OpenAI** 的 `GPT-5.5` 在用量与跑分上均显疲态，面临严峻的市场份额保卫战。

---

### 二、 核心厂商动态与用量分析

#### 1. DeepSeek：流量之王，V4 Flash 统治力确立
*   **数据表现**：`deepseek-v4-flash` 以 **3563.39B** (约3.56万亿) Token 消耗量稳居榜首，远超第二名。加上 `v3.2` 和 `v4-pro`，DeepSeek 系列模型总消耗量惊人。
*   **分析师点评**：DeepSeek 已经成功通过“Flash”系列确立了低成本、高吞吐的市场心智。其用量是 GPT-5.5 的 **6.4倍**，表明在开发者生态和应用层集成中，DeepSeek 已成为首选的“基础设施级”模型。

#### 2. Tencent：黑马突围，Hy3 预览版表现抢眼
*   **数据表现**：`tencent/hy3-preview` 消耗量达 **3400.16B**，仅次于 DeepSeek。
*   **分析师点评**：这是本周最值得关注的数据变化。Hy3 作为腾讯的新一代模型，在预览阶段即获得如此巨大的调用量，推测其已深度接入腾讯系产品矩阵（如微信、QQ浏览器等）或企业微信生态。这标志着国内大模型战场已从“创业公司独角戏”转向“互联网巨头反攻”。

#### 3. Anthropic：技术标杆，高端市场稳固
*   **数据表现**：`claude-sonnet-4.6` (1966B) 与 `claude-opus-4.7` (1959B) 分列三四名，用量旗鼓相当。
*   **跑分动态**：在 LMArena 榜单中，`claude-opus-4-6-thinking` 以 **1502分** 位居第一，`claude-opus-4-7-thinking` 紧随其后。前四名被 Anthropic 包揽。
*   **分析师点评**：Anthropic 在代码与复杂逻辑任务上持续领先。Opus 系列的高昂定价并未阻挡其用量，说明在“高价值任务”场景下，用户愿意为性能溢价买单。

#### 4. Google：Gemini 3 系列稳步爬坡
*   **数据表现**：`gemini-3-flash-preview` 消耗量 **1256B**，排名第六。
*   **跑分动态**：`gemini-3.1-pro-preview` 和 `gemini-3-pro` 均进入前十，分数在 1486-1488 区间。
*   **分析师点评**：Google 正在通过多模态优势和云生态整合追赶 OpenAI。Gemini 3 系列的用量上升表明其在多模态处理和长文本场景中正在蚕食 GPT 的市场份额。

#### 5. OpenAI：面临份额挤压
*   **数据表现**：`openai/gpt-5.5` 消耗量 **554.8B**，仅排名第 15 位。
*   **跑分动态**：`gpt-5.5-high` 跑分 1481，位列第八，不仅落后于 Anthropic 全系，也落后于 Muse Spark 和 Gemini 3 系列。
*   **分析师点评**：这是一个危险信号。作为行业标杆，GPT-5.5 在用量上被 DeepSeek 和腾讯远远甩开，在跑分上被 Anthropic 压制。OpenAI 需要尽快发布下一代模型或调整定价策略以应对“前后夹击”。

#### 6. 国内厂商动态
*   **Stepfun (阶跃)**：`step-3.5-flash` 消耗量 831B，表现稳健，在国内厂商中仅次于腾讯和 DeepSeek。
*   **Moonshot (Kimi)**：`kimi-k2.6` 消耗量 752B，排名第十。模型版本的快速迭代（K2.6）维持了其C端应用的活跃度。
*   **Minimax**：`minimax-m2.7` 消耗量 659B，排名第十三，处于第二梯队领头羊位置。

### 三、 价格体系与成本分析

根据最新 API 定价采样，市场呈现明显的“两极分化”：

1.  **极致性价比路线**：
    *   **Alibaba** 的 `tongyi-deepresearch-30b-a3b` 价格极具竞争力，输入仅 **$0.089/M**，输出 **$0.45/M**。这解释了为何国产模型在用量上能占据优势，价格战仍在持续。
    *   **Amazon** 的 `nova-micro-v1` 输入低至 **$0.034/M**，主打边缘侧和低成本场景。

2.  **高价值路线**：
    *   **Anthropic** 虽未在采样表中显示具体价格，但结合其 Opus 系列的高消耗量，推测其维持了高 ARPU 值策略。
    *   **Amazon Nova Premier** 定价高达 **$2.5/M (Input)** 和 **$12.5/M (Output)**，定位高端企业级任务。

3.  **缓存策略**：
    *   **Aion Labs** 的 `aion-2.0` 显示出 **76.17%** 的极高缓存命中率，这表明通过智能缓存降低成本已成为中间件厂商的核心优化方向。

### 四、 多模态与专项评测专区

**LMArena 综合跑分变动分析**：

*   **Thinking 模型霸榜**：榜单前两名均为 `thinking` 后缀模型（Claude Opus 4-6/4-7），证明“慢思考”（System 2）架构已成为顶尖模型的标配。
*   **多模态隐形竞争**：虽然本次数据未单独列出 Vision 跑分，但排名前列的 `Gemini-3` 系列和 `Claude-4` 系列均为原声多模态模型。
    *   **Gemini 3 Flash** 的高用量（1256B）很大程度上得益于其多模态处理能力的性价比。
    *   **Muse Spark** 作为黑马跑分达到 1489（第5名），需关注其是否在特定模态（如图像理解或代码生成）上有突破。

### 五、 投资建议与风险提示

1.  **投资建议**：
    *   **关注应用层降本红利**：DeepSeek V4 Flash 和腾讯 Hy3 的高用量验证了低成本模型在应用层的爆发力，建议关注基于此类低成本 API 构建的 AI 应用公司。
    *   **重仓 Anthropic 生态**：Anthropic 在技术跑分上的绝对领先地位，使其成为高端企业服务市场的首选标的。
    *   **警惕 OpenAI 估值风险**：GPT-5.5 的数据表现显示其护城河正在变窄，需警惕其市场份额进一步被开源模型和 Google 瓜分的风险。

2.  **风险提示**：
    *   **价格战持续**：阿里等厂商的极低定价可能进一步压缩行业利润空间，未形成规模效应的中小模型厂商面临出清风险。
    *   **数据滞后风险**：部分模型（如 `openrouter/owl-alpha`）用量激增但跑分缺失，需警惕“刷量”或特定任务优化的数据噪音。
