# 【每日大模型行业情报简报】

**日期：** 2026年5月17日
**编辑：** AI 行业投资顾问

---

### 📊 核心观点摘要

今日数据呈现出明显的**“双雄争霸，国产崛起”**态势。Anthropic 凭借 Claude Opus 4.7 系列在跑分与用量上双双登顶，确立了性能霸主地位；DeepSeek 依靠 V4-Flash 的极高性价比，占据流量榜首。值得关注的是，国产模型在流量榜单中占据半壁江山，腾讯混元与 Moonshot Kimi 的流量激增显示出应用层的爆发力。OpenAI 在跑分榜单上暂时落后于 Anthropic 与 Google 的最新模型，市场格局正在剧烈重塑。

---

### 🏆 核心厂商动态分析

#### 1. Anthropic：性能与流量的双重王者
*   **跑分霸榜**：根据 LMArena 最新数据，`claude-opus-4-6-thinking` 以 **1502分** 位居榜首，`claude-opus-4-7-thinking` 紧随其后（1500分）。Claude 系列包揽了榜单前四名，显示出其在推理能力上的绝对领先优势。
*   **流量激增**：在 Token 消耗榜单中，`claude-opus-4.7` 以 **1740亿 Token** 的消耗量位列第三，超越了旧版 `claude-opus-4.6`（629亿 Token）。这表明用户正在以极快的速度向最强模型迁移，且愿意为顶尖智力付费。

#### 2. DeepSeek：性价比驱动的流量巨头
*   **流量断层第一**：`deepseek/deepseek-v4-flash` 消耗量高达 **2038亿 Token**，仅次于腾讯混元。结合 `deepseek-v3.2`（1129亿）和 `deepseek-v4-pro`（991亿）的数据，DeepSeek 系列模型的总流量极其惊人。
*   **市场策略**：DeepSeek 采取了清晰的分层策略，Flash 版本承接海量轻量级请求，Pro 版本稳居前十。这种“高低搭配”的策略使其在 API 市场占据了稳固的基本盘。

#### 3. Google：Gemini 3 系列强势反击
*   **跑分追赶**：`gemini-3.1-pro-preview` 跑分达到 **1489分**，超越了 GPT-5.5-high（1484分），标志着 Google 在模型能力上已重回第一梯队。
*   **多模态流量**：`google/gemini-3-flash-preview` 消耗量达到 **1251亿 Token**，显示出市场对 Gemini 多模态能力的认可度正在快速提升。

#### 4. 国产力量：腾讯与 Moonshot 的爆发
*   **腾讯混元**：`tencent/hy3-preview` 以 **3088亿 Token** 的消耗量位居榜首，且大幅领先第二名。这一异常数据极可能源于微信生态或腾讯云业务场景的深度整合与放量，预示着端侧/应用侧模型的巨大潜力。
*   **Moonshot (Kimi)**：`moonshotai/kimi-k2.6` 消耗量达 **1299亿 Token**，排名第五。Kimi 模型在长文本和 Agent 场景的持续优化，使其在 C 端和 B 端 API 调用上保持了极高的活跃度。
*   **阿里与阶跃**：阿里 `tongyi-deepresearch-30b-a3b` 采样价格极低（Input $0.09/M），显示出其在开源和科研领域的价格攻势；阶跃星辰 `stepfun/step-3.5-flash` 也进入了流量前15，国产模型生态呈现百花齐放态势。

#### 5. OpenAI：相对沉寂期
*   **跑分压力**：GPT-5.5-high 跑分仅为 **1484分**，已被 Claude Opus 4 系列和 Gemini 3 系列超越。在流量前15榜单中未见 GPT 系列身影（可能因统计口径或聚合平台差异），但在跑分端的优势正在缩小。

---

### 🖼️ 多模态与垂直领域专区

*   **多模态模型流量显著上升**：
    虽然 LMArena 榜单未单独列出多模态子项，但 `google/gemini-3-flash-preview`（1251亿 Token）和 `anthropic/claude-opus-4.7` 的高消耗量侧面印证了多模态需求的爆发。Gemini 3 系列原生支持多模态，其 Flash 版本的高流量表明开发者在处理图文混合任务时，倾向于选择 Google 的高性价比方案。

*   **NVIDIA 免费模型流量可观**：
    `nvidia/nemotron-3-super-120b-a12b:free` 消耗量达 **701亿 Token**。作为榜单中少有的免费模型，NVIDIA 正通过免费策略抢占开发者生态入口，这可能是未来模型分发的一个重要趋势——硬件厂商通过模型补贴硬件销售。

---

### 💰 价格与市场动态

*   **价格战持续**：阿里 `tongyi-deepresearch-30b-a3b` 输入价格低至 **$0.09/M**，输出 **$0.45/M**，且 Cache Hit Rate 高达 **76%**，显示出其在成本控制上的极致追求。
*   **Amazon Nova 布局**：Amazon Bedrock 上的 Nova 系列模型定价亲民（Micro 版本输入仅 $0.03/M），正在构建极具竞争力的云服务模型矩阵。
*   **高端模型溢价稳固**：尽管开源和轻量模型价格极低，但 Anthropic Claude Opus 系列的高消耗量证明，市场依然愿意为顶尖的推理能力支付溢价。

---

### 📝 投资建议与风险提示

1.  **关注应用层爆发**：腾讯混元流量的异常飙升提示我们，模型与超级应用（如微信）的结合将产生巨大的网络效应，投资重心可适当向拥有超级应用入口的模型厂商倾斜。
2.  **技术迭代风险**：OpenAI 目前在跑分榜上落后于 Anthropic 和 Google，若 GPT-6 或后续版本未能及时推出，其 API 市场份额可能进一步被蚕食。
3.  **成本红利**：随着 DeepSeek、阿里等厂商不断下探价格，AI 应用的落地成本大幅降低，利好 AI Agent 和垂直 SaaS 应用开发商。
