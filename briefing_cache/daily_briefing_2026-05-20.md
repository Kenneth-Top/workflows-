### 01. 核心观点摘要

今日数据显示，大模型行业已进入**“高频迭代与用量分化”**的深水区。
1.  **用量霸主易主：** 腾讯 `hy3-preview` 与 DeepSeek `v4-flash` 包揽用量榜前二，且均为“Preview”或“Flash”轻量级版本，显示市场对**高性价比、低延迟模型**的需求呈爆发式增长。
2.  **Claude 系列强势领跑：** Anthropic 凭借 `Claude-Opus-4.6/4.7` 包揽 LMArena 跑分前四，OpenAI `GPT-5.5` 暂居下风，行业技术皇冠暂时易主。
3.  **国产模型出海加速：** DeepSeek、Moonshot (Kimi)、Stepfun (阶跃) 在全球 Token 消耗榜单中占据重要席位，DeepSeek 更是有三款模型同时进入前十。

### 02. 核心厂商动态与用量分析

#### 2.1 DeepSeek：性价比之王的“饱和式攻击”
DeepSeek 展现了极强的市场统治力，其最新发布的 `deepseek-v4-flash` 以 **2737.76B** (十亿 Token) 的消耗量位居第二，仅次于腾讯。
*   **数据支撑：** 除 V4-Flash 外，`deepseek-v3.2` (1235.73B) 与 `deepseek-v4-pro` (1054.10B) 同时跻身前十。DeepSeek 系列模型合计贡献了榜单前十中约 40% 的 Token 流量。
*   **分析师点评：** DeepSeek 采取了极其激进的版本分层策略，Flash 版本显然承担了海量轻量级推理任务，成功承接了长尾与高频需求。

#### 2.2 腾讯混元：隐形巨头的爆发
`tencent/hy3-preview` 以 **3105.78B** 的惊人消耗量登顶榜首，成为今日最大黑马。
*   **数据支撑：** 该数值超过了第二名 DeepSeek V4 Flash 约 13%，显示出腾讯在微信生态及云端产品中集成大模型的深度已达到行业顶尖水平。
*   **分析师点评：** 这标志着“应用层巨头”自研模型的内部闭环已跑通，其规模效应正在外溢。

#### 2.3 Anthropic：高端市场的绝对主力
虽然 OpenAI 未进入今日用量 Top 15（可能因统计口径或企业级私有化部署原因），但 Anthropic 表现抢眼。
*   **数据支撑：** `claude-sonnet-4.6` (1790.56B) 与 `claude-opus-4.7` (1712.88B) 分列三、四位。值得注意的是，通常昂贵的 Opus 系列能拥有如此高的消耗量，说明其在复杂任务处理上具有不可替代性。

#### 2.4 Google：Gemini 3 代初露锋芒
*   **数据支撑：** `gemini-3-flash-preview` 消耗量达 **1311.70B**，排名第五。相比之下，旧版 `gemini-2.5-flash` 已回落至 650B 左右。用户向新版本迁移的速度极快。

#### 2.5 国内厂商：Kimi 与阶跃
*   **Moonshot (Kimi)：** `kimi-k2.6` 消耗量 **1077.70B**，稳居第八。Kimi 在 C 端应用的粘性转化为了实实在在的推理量。
*   **Stepfun (阶跃星辰)：** `step-3.5-flash` 消耗量 **870.59B**，排名第十，显示出其技术架构在处理大规模并发时的稳定性。

### 04. 多模态专区

**核心发现：Gemini 3 Flash Preview 的异动**

*   **数据归因：** 在 Token 消耗榜单中，`google/gemini-3-flash-preview` 以 **1311.70B** 的流量高居第五，远超同期的 Gemini 2.5 系列。
*   **分析：** Gemini 系列历来以原生的多模态能力著称。其 V3 版本在保持 Flash 系列低延迟特性的同时，消耗量激增，暗示其在**视觉理解** 或**长上下文多模态处理** 场景中取得了突破性进展，可能已大规模应用于视频分析或文档解析领域。
*   **竞对对比：** 榜单中并未出现专门的“Vision”后缀模型挤入前列，这表明多模态能力正在从“附加功能”转变为旗舰模型的“标配能力”（如 Claude Opus 4.7 和 GPT-5.5 均默认包含视觉能力）。

### 05. 价格与成本分析

*   **阿里通义：** `alibaba/tongyi-deepresearch-30b-a3b` 录得 **96%** 的极高缓存命中率，输入价格低至 **$0.089/M**。这表明阿里在推理优化架构上做得极为出色，通过 KV Cache 技术大幅降低了实际服务成本。
*   **Amazon Nova：** Nova Pro V1 价格约为 $0.79/M，定位中端市场，试图填补开源模型与顶尖闭源模型之间的空白。

### 06. 投资建议

1.  **关注推理侧成本优化：** DeepSeek V4 Flash 和腾讯 HY3 的用量霸榜证明，**“极致性价比”**是目前市场扩容的核心驱动力。建议关注具备强推理优化能力的算力调度平台。
2.  **重新评估 Anthropic 估值：** Claude Opus 4 系列在跑分和用量上的双重胜利，确立了其在“高智力密度”市场的领导地位，其商业化变现能力正在被低估。
3.  **警惕 OpenAI 的技术迭代周期：** GPT-5.5 在跑分上的落后可能引发市场对 OpenAI 技术领先性的担忧，需密切关注其后续 GPT-6 的发布节奏。
