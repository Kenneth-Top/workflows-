### 2. 核心厂商用量与动量分析

基于近 7 天 Token 消耗数据（单位：Billion），市场头部效应显著，国产模型出海势头强劲。

#### **第一梯队：流量巨头 ( > 1,000B )**
*   **Tencent (腾讯混元)**
    *   **模型**：`tencent/hy3-preview`
    *   **数据**：消耗 **3,160.9 B**，位居榜首。
    *   **分析**：腾讯混元以断层优势领先，推测其近期在微信生态或企业级应用端完成了大规模的推理负载迁移，`hy3-preview` 可能是针对高并发场景优化的轻量级或混合专家模型。
*   **DeepSeek (深度求索)**
    *   **模型**：`deepseek-v4-flash` (2,997.8 B, Rank 2) 与 `deepseek-v4-pro` (1,085.7 B, Rank 8)。
    *   **分析**：DeepSeek 延续了“价格屠夫”策略带来的流量红利。V4-Flash 版本作为主力模型，消耗量逼近 3 Trillion，显示出极低的调用门槛正在吸引海量长尾与中间层开发者。V3.2 版本仍有存量市场，但 V4 系列已成绝对主力。
*   **Anthropic**
    *   **模型**：`claude-sonnet-4.6` (1,815.2 B, Rank 3) 与 `claude-opus-4.7` (1,666.5 B, Rank 4)。
    *   **分析**：Sonnet 与 Opus 的高昂用量证明了其在前端应用（如 Cursor、Claude Artifacts）中的不可替代性。Opus 4.7 作为旗舰模型能进入前四，说明用户愿意为高质量推理支付高溢价。

#### **第二梯队：稳健增长 ( 500B - 1,000B )**
*   **Google Gemini**：`gemini-3-flash-preview` (1,295.9 B) 表现亮眼，超越自家 `gemini-2.5-flash`，说明 Gemini 3 系列预览版已获得市场积极反馈。
*   **Moonshot (Kimi)**：`kimi-k2.6` 消耗 **989.2 B**，稳居第 9 名。作为国产应用层代表，其 API 化程度正在加深。
*   **Stepfun (阶跃星辰)**：`step-3.5-flash` 消耗 **896.4 B**，显示出国产新势力在推理速度优化上的成效。
*   **MiniMax**：`minimax-m2.7` 消耗 **758.8 B**，保持在第一阵营。

### 3. 技术前沿与跑分变动

LMArena 最新榜单（2026-05-21）显示，推理模型已成为顶尖对决的关键。

*   **Anthropic 暂居第一**：
    *   `Claude-Opus-4.6-Thinking` 以 **1502 分** 夺魁。
    *   `Claude-Opus-4.7-Thinking` 紧随其后（1500分）。
    *   **点评**：Anthropic 在“Thinking”（思维链/慢思考）模式上的深耕见效，Opus 4.6 的非 Thinking 版本也达到了 1498 分，显示出基础模型能力的全面提升。

*   **Google 紧追不舍**：
    *   `Gemini-3.1-Pro-Preview` (1488分) 和 `Gemini-3-Pro` (1486分) 占据榜单中段。
    *   **点评**：Gemini 3 系列与 Claude Opus 4 系列分差在 15 分以内，属于同一梯队，但在顶尖推理上略逊于 Claude 的 Thinking 模式。

*   **OpenAI 的挑战**：
    *   `GPT-5.5-high` 目前得分 **1481 分**，位列第 8。
    *   **点评**：OpenAI 在此次采样周期内排名略显落后，GPT-5.5 虽然仍是顶级模型，但在面对 Claude 和 Google 的新一代“Thinking”架构模型时，竞技场优势不再明显。

### 4. 多模态专区

*注：本次数据库采样中 LMArena 的多模态分项数据缺失，但结合用量与模型特性分析如下：*

*   **Gemini 3 Flash 的多模态渗透**：
    `gemini-3-flash-preview` 拥有高达 **1,295.9 B** 的调用量。考虑到 Gemini 系列原生的多模态属性，推测大量调用包含视觉任务。其排名（总榜第 6）远高于纯文本或弱多模态模型，证明了**多模态“普惠化”**趋势——即 Flash 级别模型已能以低成本处理绝大多数图文任务。

*   **Claude 系列的视觉能力**：
    `Claude-Sonet-4.6` 的高流量（Rank 3）部分归功于其在代码生成与图表解读（Vision）上的均衡表现。虽然跑分表未列出 Vision 分数，但 Opus/Sonet 系列一直是多模态编程辅助的首选。

### 5. 价格与成本策略

*   **Amazon Nova 2 的低价突袭**：
    *   `amazon/nova-2-lite-v1` 输入价格 **$0.299/M**，输出 **$2.5/M**。
    *   `amazon/nova-micro-v1` 输入价格低至 **$0.034/M**。
    *   **分析**：AWS 正通过 Nova 系列构建“价格护城河”。Micro 版本不足 $0.04/M 的价格，直接对标 DeepSeek 的低成本策略，旨在锁定对延迟不敏感、追求极致性价比的云端存量用户。

*   **DeepSeek 的隐性优势**：
    虽然今日采样中未直接列出 DeepSeek V4 的具体报价，但其 V4-Flash 模型高达 3 Trillion 的消耗量暗示了其极低的边际成本。结合 Amazon Nova 的定价策略，预计下一阶段 API 市场的竞争焦点将从“跑分”转向“单位智能成本”。

### 6. 投资建议与风险提示

*   **关注点**：
    1.  **推理模型商业化**：Claude Opus Thinking 版本的高分与高用量并存，验证了“慢思考”模型在 B 端复杂任务中的付费意愿，建议关注具备强推理架构优化的初创公司。
    2.  **国产模型出海红利**：DeepSeek、Stepfun、MiniMax 在全球 API 流量榜上的高位次，表明国产模型在非中文市场的渗透率正在通过“高性价比”快速提升。

*   **风险点**：
    1.  **价格战加剧**：Amazon 等云厂商下场做基础模型并定出地板价，可能压缩独立模型厂商（如 AI21, Aion Labs）的生存空间。
    2.  **版本迭代过快**：Gemini 3 与 Claude 4.6/4.7 的快速迭代，可能导致基于旧版本（如 GPT-5.4, Gemini 2.5）构建的应用面临性能折旧风险。
