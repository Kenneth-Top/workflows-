# 【每日大模型行业情报简报】
**日期：2026年5月13日**

---

### 核心摘要
今日数据显示，大模型行业呈现**“量价齐杀”与“头部争霸”**并存的格局。
1.  **用量激增**：Tencent HY3 与 Moonshot Kimi K2.6 消耗量爆发，国产模型在 API 调用量上已形成第一梯队优势。
2.  **格局生变**：OpenAI 未出现在消耗榜前 15 名，而 Anthropic 凭借 Claude 4.x 系列在高端市场稳固站位，且在跑分榜上压制 GPT-5.5。
3.  **价格战底线**：Amazon 与 Alibaba 将输入价格击穿至 $0.03-$0.08/M 区间，模型推理正式进入“微利时代”。

---

### 一、 核心厂商动态与用量分析

#### 1. 腾讯 & 月之暗面：国产算力霸榜
**数据表现**：
*   **Tencent HY3** 系列模型（preview + free）合计消耗量突破 **3763亿 Tokens**，位居榜首。其中免费版 `hy3-preview:free` 单项消耗达 2071亿，显示出极强的 C 端渗透力。
*   **Moonshot Kimi K2.6** 以 **1748亿** 的消耗量紧随其后，超越了 Anthropic 的主力付费模型。

**分析师点评**：
腾讯混元（HY3）与 Kimi 的数据表明，国产模型在中文语境与应用生态整合上已形成极高壁垒。免费策略极大地拉动了 Token 消耗规模，这种“流量换模型”的策略正在重塑 API 市场的份额格局。

#### 2. Anthropic：高端市场的绝对王者
**数据表现**：
*   **Claude Sonnet 4.6** 消耗量 **1746亿**，与 Kimi K2.6 持平，是付费模型中消耗量最高的主力。
*   **Claude Opus 4.7** 消耗量达 **1603亿**，作为高价旗舰模型，其高消耗量证明了 B 端用户对高质量推理的付费意愿极强。

**跑分动态**：
在 LMArena 榜单中，`claude-opus-4-6-thinking` 以 **1502分** 位居第一，`claude-opus-4-7-thinking` 紧随其后（1501分）。Anthropic 在推理能力上已实现对 OpenAI 的反超。

#### 3. DeepSeek：性价比之王的持续渗透
**数据表现**：
*   **DeepSeek V4 Flash** 消耗量 **1411亿**，V3.2 消耗量 **1019亿**，V4 Pro 消耗量 **971亿**。
*   DeepSeek 系列模型占据了消耗榜 3 个席位，显示出其“多代同堂”的策略在成本敏感型开发者中极具吸引力。

#### 4. Google：Gemini 3 的反击
**数据表现**：
*   **Gemini 3 Flash Preview** 消耗量 **1288亿**，排名靠前。
*   跑分方面，`gemini-3.1-pro-preview` 获得 **1490分**，超越了 GPT-5.4-high，显示出 Google 在模型能力上的快速追赶。

#### 5. OpenAI：缺席消耗榜，跑分承压
**异常信号**：
*   在 Token 消耗前 15 名中，**未见 OpenAI (GPT系列) 模型身影**。这可能意味着其 API 市场份额被开源及国产低价模型大幅挤压，或存在数据采样偏差。
*   跑分方面，`gpt-5.5-high` 仅列第 8 位（1484分），落后于 Claude 和 Gemini 的最新版本。OpenAI 急需发布下一代模型以挽回颜面。

### 二、 价格趋势与成本分析

今日 API 定价数据显示，推理成本已降至冰点，行业进入“白菜价”阶段：

*   **极致低价区间**：
    *   **Amazon Nova Micro**：输入价格低至 **$0.034/M**，输出 **$0.13/M**。
    *   **Alibaba Tongyi DeepResearch**：输入 **$0.089/M**，输出 **$0.45/M**。
    *   **Aion Labs Aion-2.0**：输入 **$0.32/M**，且 Cache Hit Rate（缓存命中率）高达 **79.38%**，实际有效成本更低。

*   **高价区间**：
    *   **Amazon Nova Premier**：输入 **$2.5/M**，输出 **$12.5/M**，定位高端复杂任务。
    *   **Anthropic Claude**：虽未在采样表中列出具体价格，但结合其高消耗量与高跑分，推测其维持了高溢价策略，成功实现了“量价齐升”。

**投资建议**：模型厂商的毛利率正在快速收窄，未来的竞争焦点将从“价格战”转向“生态战”与“高价值推理能力（如 Agent/Thinking 模式）”。

### 三、 多模态与推理能力专区

**Thinking 模式成为新标杆**：
LMArena 榜单前两名均被 `thinking` 后缀模型占据（Claude Opus 4-6/4-7 Thinking）。这表明行业评价标准已从单纯的文本生成转向复杂逻辑推理。

**Vision/多模态动态**：
*   虽然今日采样数据中未直接列出 Vision 跑分，但 **Gemini 3 Flash** 的高消耗量（1288亿）通常与其多模态处理能力强相关。
*   **Tencent HY3** 的高消耗量亦可能包含多模态（如视频/图像生成 preview）的调用，建议后续密切关注 HY3 在多模态领域的具体拆分数据。

### 四、 风险提示与重点关注

1.  **OpenAI 动向**：GPT 系列在消耗榜的缺席是一个危险信号，需警惕其市场份额被 Anthropic 和 Google 瓜分的风险。
2.  **免费模型冲击**：`tencent/hy3-preview:free` 和 `nvidia/nemotron-3-super-120b-a12b:free` 的高流量显示，免费策略仍是获取市场份额的最有效手段，但这将对初创模型公司的商业化构成严峻挑战。
3.  **数据来源**：今日网络搜索资讯多为通用页面，缺乏具体产品发布新闻，本简报主要基于数据库客观数据进行分析。建议投资者关注各大厂商即将发布的季度财报中的 AI 业务营收拆分。
