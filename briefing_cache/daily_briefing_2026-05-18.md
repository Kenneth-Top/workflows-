### 🚀 核心厂商动态与流量分析

#### 1. 国产模型流量爆发：腾讯与 DeepSeek 领跑
近 7 天 Token 消耗数据显示，国产模型占据了流量榜首，显示出极高的市场渗透率：
*   **腾讯**：`tencent/hy3-preview` 以 **3066.48B** (3万亿+) 的 Token 消耗量位居第一，远超第二名。这表明腾讯在社交或应用端的大模型集成已进入大规模落地阶段。
*   **DeepSeek**：`deepseek-v4-flash` 消耗量达 **2235.82B**，位居第二。结合其通常具备的高性价比特性，推测其为当前开发者生态中最活跃的推理模型。同时，`deepseek-v3.2` 与 `deepseek-v4-pro` 也在前 15 名中占据两席，显示出其模型矩阵的完整性。

#### 2. Anthropic：高端模型用量坚挺
*   `claude-opus-4.7` 与 `claude-sonnet-4.6` 分别录得 **1691.66B** 和 **1675.84B** 的消耗量，排名第三、第四。
*   **分析**：在 Opus 级别的高定价下仍能保持如此巨大的调用量，说明 Claude 系列在代码、写作等高价值场景中具有不可替代性。

#### 3. Google Gemini 3 系列快速起量
*   `google/gemini-3-flash-preview` 消耗量达 **1270.13B**，排名第五。作为预览版模型，其流量已超越 OpenAI 的多款主力模型（未在 Top 15 出现），反映出 Google 在多模态与长上下文领域的激进策略正在奏效。

#### 4. Moonshot (Kimi) 与 Minimax
*   `moonshotai/kimi-k2.6` 消耗量 **1216.39B**，排名第六，表现稳健。
*   `minimax/minimax-m2.7` 排名第十，流量为 **844.83B**。

### 🎨 多模态专区

虽然数据库未直接提供多模态跑分详情，但从流量与模型迭代趋势分析：

1.  **Gemini 3 Flash 的多模态渗透**：`gemini-3-flash-preview` 拥有超过 1.2 万亿 Token 的消耗量。鉴于 Gemini 系列原生的多模态属性，推测大量调用包含视觉理解任务。其高流量暗示多模态应用已从“尝鲜”转向“规模化生产”。
2.  **Claude 的视觉能力**：`Claude Opus 4.7` 系列在 LMArena 的高分通常包含 Vision 评测权重。Anthropic 在保持文本推理优势的同时，其视觉理解能力（图表分析、OCR等）可能也是其维持高 API 调用单价（参考 Haiku 4.5 定价）的关键支撑。

### 💰 定价与成本分析

根据 2026-05-18 的 API 定价采样：
*   **Anthropic 溢价明显**：`claude-haiku-4.5` 的 Input 价格为 **$0.88/M**，Output 价格高达 **$5.00/M**。相比之下，旧版 `claude-3-haiku` 仅为 $0.24/$1.24。Haiku 4.5 价格涨幅巨大，这通常意味着模型能力（如指令遵循、推理速度）有质的飞跃，或者厂商开始通过品牌溢价筛选高价值客户。
*   **Amazon Nova 策略**：`amazon/nova-2-lite-v1` 定价 ($0.29/$2.49) 介于入门与高端之间，结合 AWS 的生态分发能力，这是典型的云厂商“中间路线”定价策略。
*   **免费/低价模型**：`nvidia/nemotron-3-super-120b-a12b:free` 出现在流量榜第 12 名，证明免费策略依然能有效获取长尾流量，适合生态建设。

### 📝 总结与建议

**市场格局：**
当前市场呈现 **"Claude 拔高上限，DeepSeek/Tencent 做大底座"** 的双轨制格局。Anthropic 在高端推理领域暂时领先，而国产模型通过极致的性价比和大规模应用场景占据了流量入口。

**风险提示：**
*   OpenAI 目前在跑分榜上落后，需警惕其后续版本（如 GPT-5.6）的反击能力。
*   API 价格波动剧烈（如 Haiku 系列涨价），下游应用需做好成本控制或多模型切换准备。

**建议关注：**
*   **DeepSeek V4** 的后续迭代及其对市场价格体系的影响。
*   **Muse-Spark** 模型的背景，作为榜单黑马可能带来新的竞争变量。
