### 📊 核心观点摘要

今日数据显示，大模型行业格局发生显著震荡。**腾讯** 凭借 `hy3-preview` 异军突起，以 2390 亿 Token 的日消耗量霸榜，打破了海外模型对算力消耗的垄断。**Anthropic** 依然保持极强的统治力，Claude 4.7/4.6 系列在跑分与用量上双双领跑高端市场。**OpenAI** 在本次数据周期内略显沉寂，GPT-5.5 系列在跑分榜上被 Claude 和 Gemini 压制，且未进入消耗量前 15 名，面临较大的市场竞争压力。

### 1. 核心厂商动态与用量分析

#### 🚀 腾讯：黑马突围，算力消耗登顶
*   **数据表现**：`tencent/hy3-preview` 以 **2390.18 亿** Token 的消耗量位居榜首，远超第二名 Claude Opus 4.7（1796.3 亿）。同时，其免费版本 `tencent/hy3-preview:free` 也录得 957.6 亿的消耗量，排名第 9。
*   **分析师点评**：腾讯 Hy3 模型的爆发式增长极其罕见，单日 2000 亿级别的消耗量暗示其可能在国民级应用（如微信生态）中完成了深度集成，或发起了大规模的免费/低价推广活动。这标志着国产大模型在 C 端流量争夺战中取得了阶段性胜利。

#### 🏆 Anthropic：高端市场绝对王者
*   **数据表现**：
    *   **用量**：`claude-opus-4.7` (1796亿) 与 `claude-sonnet-4.6` (1763亿) 紧随腾讯之后，分列二、三位，显示出极高的商业粘性。
    *   **跑分**：在 LMArena 榜单中，`claude-opus-4-6-thinking` 以 **1502 分** 夺冠，`claude-opus-4-7-thinking` 以 1500 分紧随其后。
*   **分析师点评**：Anthropic 成功构建了“高性能=高消耗”的商业闭环。其 Thinking 系列模型在复杂逻辑任务上的卓越表现（包揽前二），支撑了其高昂的 API 定价与高消耗量，是目前 B 端生产力市场的首选。

#### 📉 OpenAI：跑分落后，流量缺席
*   **数据表现**：
    *   **跑分**：`gpt-5.5-high` 仅以 1484 分位列第 8，落后于 Claude Opus/Gemini 系列及 Muse 模型。
    *   **用量**：在消耗量前 15 名中未见 GPT 系列身影。
*   **分析师点评**：OpenAI 目前处于产品迭代的各种压力期。跑分被竞品超越，且在开源/低成本模型的冲击下（如 DeepSeek），其 API 流量可能被分流。需警惕其市场占有率进一步下滑的风险。

#### ⚡ DeepSeek：性价比之王，多模型矩阵成型
*   **数据表现**：`deepseek-v4-flash` (1608亿) 排名第 4，`deepseek-v3.2` (1078亿) 与 `deepseek-v4-pro` (1006亿) 亦在榜内。
*   **分析师点评**：DeepSeek 是本次统计中唯一拥有 3 个模型进入前 15 的厂商。Flash 版本的高消耗量验证了其“极致性价比”策略的成功，正在快速抢占对成本敏感的中长尾开发者市场。

#### 🌙 Moonshot (Kimi) & Google：稳扎稳打
*   **Moonshot**：`kimi-k2.6` 消耗量达 1510 亿，排名第 5，显示出其在国内 C 端助手市场的稳固地位。
*   **Google**：`gemini-3-flash-preview` (1291亿) 排名第 6，跑分方面 `gemini-3.1-pro-preview` 达到 1489 分，仅次于 Claude，显示出 Gemini 3 代产品的强劲竞争力。

### 2. 技术前沿与跑分变动

本次 LMArena 跑分榜单（2026-05-15）揭示了技术风向的重大转变：

*   **"Thinking" 模式成为顶配标配**：榜单前两名均为带 `thinking` 后缀的 Claude 模型，且分数突破 1500 分大关。这表明市场对模型推理深度的需求已超越简单的对话生成。
*   **新势力崛起**：名为 `muse-spark` 的模型以 1490 分杀入前五，超越了 GPT-5.4/5.5，值得投资人关注其背后的团队背景。
*   **Grok 追赶**：xAI 的 `grok-4.20-beta1` 取得 1479 分，已逼近 GPT-5.4-high 水平，显示出 X 平台在模型训练上的快速迭代能力。

### 3. 多模态专区

虽然本次数据库摘要未直接提供 Vision 专项跑分，但结合模型命名规则与消耗数据，我们观察到以下多模态趋势：

*   **Gemini 3 系列的多模态潜力**：`gemini-3-flash-preview` 的高消耗量（1291亿）与其原生多模态架构密切相关。Google 在多模态输入（视频、音频流）方面的优势是其维持高消耗的核心驱动力。
*   **Claude 4.7 的视觉能力渗透**：`claude-opus-4.7` 的高昂定价与高消耗量暗示其在处理复杂图文混合文档（如代码库分析、科研论文）方面具有不可替代性。
*   **投资建议**：建议重点关注原生多模态模型在端侧应用（如实时视频理解）的落地情况。随着 `gemini-3` 和 `claude-4.7` 的普及，纯文本模型的市场份额将被进一步压缩。

### 4. API 价格与成本分析

根据 2026-05-15 的定价采样，行业价格战已进入“分层博弈”阶段：

*   **极致低价层**：
    *   **Amazon Nova Micro**：输入低至 **$0.034/M**，输出 **$0.133/M**。
    *   **Alibaba Tongyi DeepResearch**：输入 **$0.089/M**。
    *   **分析**：云厂商正通过极低价格锁定生态流量，这将对独立模型创业公司构成严峻的生存挤压。

*   **高性能溢价层**：
    *   **Amazon Nova Premier**：输入 **$2.5/M**，输出 **$12.5/M**。
    *   **AI21 Jamba Large**：输入 **$2.0/M**，输出 **$8.0/M**。
    *   **分析**：尽管开源和低价模型泛滥，但在企业级复杂任务处理上，高性能模型依然拥有极强的定价权。Anthropic 虽未在采样表中列出具体价格，但根据其消耗量推断，其 Opus 系列依然维持了高 ARPU 值。

### 💡 投资建议

1.  **关注腾讯生态链**：`hy3-preview` 的爆发式数据表明腾讯在大模型落地层面取得了突破，建议关注相关算力供应链及下游应用合作伙伴。
2.  **警惕 OpenAI 估值风险**：GPT 系列在跑分和流量上的双重疲软是一个危险信号，建议重新评估其在 AGI 竞赛中的领先优势。
3.  **布局推理侧算力**：Thinking 类模型的崛起意味着单次推理算力消耗倍增，利好高性能推理芯片及算力租赁服务商。
